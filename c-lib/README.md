# README #

### What is this repository for? ###

* Quick summary
    * This is the cola' Type library. It's a typescript library which both cola-front-end and colc-library should install to be able to work with same type of objects.
* Version

### How do I get set up? ###
There is no setting up. You should Update your types, then build it and commit everything in ./dist as well so that when other projects install the library, can have access to types both runtime and build-time.
* run the following command to build
     *     npm run build

* Dependencies
* Database configuration
* How to run tests
